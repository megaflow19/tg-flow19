# TG Flow19 1.0.6

Fixes media and stickers hanging on mobile networks where Cloudflare TLS works only through an
alternate address.

## What changed

- **HTTP/2 media use the same Cloudflare address as other connections.** On some mobile networks
  plain TLS passes only through an alternate Cloudflare address, while the usual address drops it.
  After 1.0.5's background recheck brought TLS back there, HTTP/2 media kept dialing the usual
  address, and every media download waited 8 seconds and failed. HTTP/2 now uses the address that
  WebSocket connections try first on that network.
- **HTTP/2 pauses after a setup timeout.** If an HTTP/2 connection still cannot be set up in time on
  a network, media go over WebSocket at once for the next 10 minutes instead of waiting each time.
- **A split handshake that freezes again is skipped much longer:** 1 day after the first freeze on
  a network, then 7 days, then 30 days (was doubling from 1 day). A freeze remembered by 1.0.4
  counts too. Each retry froze media for about a minute on networks seen so far.
- Diagnostics: `h2_paused` when HTTP/2 is paused on a network.

## Updating

- **Obtainium:** updates as usual from `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.6.apk` below and install it over 1.0.5; settings are kept.

Requires **Android 8.0 or newer**. One universal APK (arm64-v8a, armeabi-v7a, x86, x86_64).
