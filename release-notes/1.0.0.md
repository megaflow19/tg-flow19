# TG Flow19 1.0.0

First release of **TG Flow19**, a fork of [crim50n/tg-ws-proxy-android](https://github.com/crim50n/tg-ws-proxy-android)
(TG WS Proxy 2.1.0), which is based on [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
(commit `6690b78`). Not affiliated with crim50n, Flowseal or Telegram.

TG Flow19 has its own app ID (`io.github.megaflow19.tgflow19`), so it installs alongside TG WS Proxy
and does not update over it.

## First start

1. Open the app. A **first-time setup** guides you through notifications, battery optimization, the
   phone maker's app launch settings (Honor, Huawei, Xiaomi and others) and connecting Telegram.
   You can open it again from **Settings → Support → First-time setup**.
2. When adding the proxy to Telegram, delete old entries of this proxy first, then fully close
   Telegram (swipe it away in your recent apps) and open it again.
3. On networks that block the usual Cloudflare addresses, the **first connection can take up to
   about 30 seconds** while the app finds another route. The status line shows this; after that the
   route is remembered for the network and connections are fast.

## Changes from TG WS Proxy 2.1.0

### Connectivity
- **Alternate Cloudflare addresses.** Some networks block the exact Cloudflare addresses that DNS
  returns for the proxy domains, while other Cloudflare addresses still work. When the usual address
  does not respond, the app tries alternate Cloudflare addresses, remembers the one that works for
  the current network and goes straight to it next time (also for HTTP/2 media). Losing the network
  for a moment does not count as a blocked address.
- **Cloudflare proxy route works on networks that filter `kws*` names.** The TLS SNI is now the
  bare Cloudflare domain, and `kwsN.<domain>` is sent only in the HTTP `Host` header inside TLS.
- **Faster fallback:** the app waits 6 seconds instead of 10 for a Cloudflare address that does not
  answer.
- **Frozen direct media is remembered per network.** When direct WebSocket media freezes on a
  network (the handshake succeeds, then no data arrives), media of all data centers on that network
  goes through Cloudflare for 30 minutes. This survives proxy restarts on the same network, and a
  freeze is detected after 6 seconds of silence instead of 15.
- **Route checks after start and network changes** and **updates of the shared Cloudflare domain
  list** are now on by default.

### Reliability
- **Fixed a crash when the network changes** (`ConcurrentModificationException` while closing
  pending connections).
- **Background protection.** Some phones freeze or kill background apps even when they show a
  notification, so Telegram stops connecting until the app is opened. The app now shows a warning
  while battery optimization is on, with a button for the system "allow running in the background"
  dialog, and adds **Settings → Power usage → App launch (your phone brand)**, a shortcut to the
  phone maker's screen where auto-launch and background running are allowed.

### Interface
- First-time setup wizard (see above).
- The status line says when the app is searching for another route.

### Diagnostics
- `process_paused` events show when the system froze the proxy or the phone slept.
- `background_protection` records the battery-optimization state at startup.
- `cf_edge_used` / `cf_edge_failed` show which alternate Cloudflare address was used.
- HTTP/2 errors include their code, and rejected local handshakes include safe details.

## Install

Requires **Android 8.0 or newer**. There is **one universal APK** for all architectures
(arm64-v8a, armeabi-v7a, x86, x86_64).

- **Obtainium:** add `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.0.apk` below and check it against `tg-flow19-1.0.0.apk.sha256`.

Release APKs are signed with this certificate (SHA-256):
