# TG Flow19 1.0.4

Recognizes connections that the network cuts off mid-stream, and tells networks apart reliably.

## What changed

- **Cut-off connections are recognized while they are still open.** On some networks a Cloudflare
  connection passes 10-30 KB and then nothing comes back; Telegram kept reconnecting and showed
  "Updating" while the app looked connected. The app now notices requests left unanswered for
  6 seconds (and checks again when the session ends), so Auto mode switches to the next step within
  about 40 seconds. Open connections are not closed by this check, and a slow upload is not counted.
- **A frozen split handshake is skipped for 24 hours** on that network (was 6 hours), so hourly
  rechecks no longer bring the freeze back.
- **Port 80 also uses alternate Cloudflare addresses.** When the usual address of the proxy domains
  is blocked, port 80 connections go to an alternate Cloudflare address instead of waiting 6 seconds
  each time. The background route check uses the same address.
- **Networks are told apart by their router.** Two Wi-Fi networks whose routers share a factory
  gateway address no longer share settings: the app uses the router's IPv6 link-local address
  (derived from its hardware address) without any extra permission; only a hash is stored. The
  identity is refined a moment after connecting, so a reconnect keeps the remembered step. The
  alternate Cloudflare address is remembered the same way.
- Diagnostics: `network_changed` shows a short tail of the network key, `network_key_updated`
  when it is refined, and `session_completed` shows the unanswered tail of each session.

## Updating

- **Obtainium:** updates as usual from `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.4.apk` below and install it over 1.0.3; settings are kept.

Requires **Android 8.0 or newer**. One universal APK (arm64-v8a, armeabi-v7a, x86, x86_64).
