# TG Flow19 1.0.0

First release of **TG Flow19**, a fork of [crim50n/tg-ws-proxy-android](https://github.com/crim50n/tg-ws-proxy-android)
(TG WS Proxy 2.1.0), which is based on [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
(commit `6690b78`). Not affiliated with crim50n, Flowseal or Telegram.

TG Flow19 has its own app ID (`io.github.megaflow19.tgflow19`), so it installs alongside TG WS Proxy
and does not update over it. After installing, add the proxy link from the app to Telegram again.

## Changes from TG WS Proxy 2.1.0

### Connectivity
- **Cloudflare proxy route works on networks that filter `kws*` names.** The TLS SNI is now the
  bare Cloudflare domain, and `kwsN.<domain>` is sent only in the HTTP `Host` header inside TLS.
  Before, on such networks every Cloudflare attempt timed out. This also covers HTTP/2 media.
- **Frozen direct media is remembered per network.** When direct WebSocket media freezes on a
  network (the handshake succeeds, then no data arrives), media of all data centers on that network
  goes through Cloudflare for 30 minutes. This now survives proxy restarts on the same network, and
  a freeze is detected after 6 seconds of silence instead of 15.

### Reliability
- **Fixed a crash when the network changes** (`ConcurrentModificationException` while closing
  pending connections).
- **Background protection.** Some phones (Honor, Huawei, Xiaomi and others) freeze or kill
  background apps even when they show a notification, so Telegram stops connecting until the app is
  opened. The app now:
  - shows a warning on the main screen while battery optimization is on, with a button that opens
    the system "allow running in the background" dialog;
  - adds **Settings → Power → App launch (your phone brand)**, a shortcut to the phone maker's
    screen where auto-launch and background running are allowed.

### Diagnostics
- `process_paused` events show when the system froze the proxy or the phone slept.
- `background_protection` records the battery-optimization state at startup.
- HTTP/2 errors include their code, and rejected local handshakes include safe details.

## Install

Requires **Android 8.0 or newer**. There is **one universal APK** for all architectures
(arm64-v8a, armeabi-v7a, x86, x86_64).

- **Obtainium:** add `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.0.apk` below and check it against `tg-flow19-1.0.0.apk.sha256`.

Release APKs are signed with this certificate (SHA-256):
