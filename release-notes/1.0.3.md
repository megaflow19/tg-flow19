# TG Flow19 1.0.3

Faster and steadier fallback on networks that block the Cloudflare proxy domains.

## What changed

- **Frozen connections are recognized within seconds.** On some networks the split TLS handshake
  passes, but then almost nothing comes back. Auto mode used to notice this only on media streams,
  and often only after several minutes; now every Cloudflare connection that sends requests and
  gets (almost) nothing back counts, and three of them within two minutes switch the network to
  port 80. In testing the switch took about 20 seconds instead of several minutes or never.
- **The working step is remembered per network across reconnects and restarts.** Reconnecting to
  the same Wi-Fi or mobile network (and restarting the app or the phone) no longer starts the
  search over. Networks are recognized by the Wi-Fi gateway or the SIM card; only a short hash is
  stored, on the phone. Plain TLS is still rechecked every hour.
- **No more sudden reconnects after the route was found.** Switching to "Cloudflare first"
  automatically no longer restarts the proxy and drops Telegram's open connections.
- **HTTP/2 media:** when the Cloudflare proxy refuses HTTP/2 requests, the app no longer passes this
  to Telegram as an MTProto error (which made media hang at start); it uses WebSocket media for
  30 minutes instead.
- An alternate Cloudflare address that just dropped a handshake is no longer tried first by
  connections opened at the same moment.
- Diagnostics: `network_changed` shows the network type (`kind=wifi|cellular`); `session_completed`
  shows which side closed the session (`endedBy`), the transport and whether it counted as frozen.

## Updating

- **Obtainium:** updates as usual from `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.3.apk` below and install it over 1.0.2; settings are kept.

Requires **Android 8.0 or newer**. One universal APK (arm64-v8a, armeabi-v7a, x86, x86_64).
