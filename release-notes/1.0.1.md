# TG Flow19 1.0.1

Fixes the **Google Play Protect "Harmful app blocked"** warning when installing or updating TG Flow19
outside Google Play (for example with Obtainium).

## What changed

- **No more in-app update installer.** The app no longer downloads APKs or asks Android to install
  them, and it no longer requests the "install unknown apps" permission. On a new developer's app,
  Play Protect treats that combination as harmful. Tests on a device confirmed that the same code
  without the in-app installer is reported as safe.
- The app still checks GitHub releases and tells you when a new version is out; the update button
  now opens the release page.
- Help texts about updates and power usage are up to date (route checks and Cloudflare domain list
  updates are on by default since 1.0.0).

## Updating

- **Obtainium:** updates as usual from `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.1.apk` below and install it over 1.0.0; settings are kept.
- If 1.0.0 was blocked by Play Protect, install 1.0.1 directly.

Requires **Android 8.0 or newer**. One universal APK (arm64-v8a, armeabi-v7a, x86, x86_64).

Release APKs are signed with this certificate (SHA-256):
