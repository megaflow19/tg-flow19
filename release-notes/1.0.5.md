# TG Flow19 1.0.5

No more hourly pauses while the app checks whether plain TLS works again, and less wasted work when
the network is fading or Telegram gives up on a connection.

## What changed

- **TLS is rechecked in the background.** On networks where the app had to step down from plain TLS,
  it used to retry TLS on Telegram's own connections every hour; where TLS stayed blocked, that cost
  Telegram 5-50 seconds each time, and once about 5 minutes. Now a separate test connection does the
  check and Telegram's connections stay on the working step. While TLS stays blocked, rechecks
  become less frequent: after 1 hour, then 2, 4, 8, 16 hours, then once a day.
- **A split handshake that freezes again is skipped longer.** Each new freeze on the same network
  doubles how long the split step is skipped there: 1 day, then 2, 4, 8, 16 and up to 30 days.
- **No storm of attempts on a fading network.** When the phone has no route at all (Wi-Fi going
  away before the phone switches networks), the app no longer tries every proxy domain for each
  Telegram connection; one attempt shows there is no route.
- **Dialing stops when Telegram gives up.** If Telegram closes a connection while the app is still
  connecting it upstream, the attempt is cancelled instead of running on (adapted from Flowseal
  v1.12.0 and crim50n v2.1.2).
- **Deadlines for connection setup.** Direct WebSocket setup must finish within its timeout as a
  whole, and the first write to a new connection within 10 seconds.
- Texts: the "Searching for another route" message now says it can take 40-75 seconds, and the old
  proxy entries warning says to fully close Telegram after deleting them.
- Built for Android 15 (target SDK 35). The release workflow uses current GitHub Actions versions.
- Diagnostics: `cf_transport_recheck` shows the result and when the next recheck is due;
  `cf_domains_skipped` and `upstream_setup_cancelled` are new.

## Updating

- **Obtainium:** updates as usual from `https://github.com/megaflow19/tg-flow19`.
- **Manually:** download `tg-flow19-1.0.5.apk` below and install it over 1.0.4; settings are kept.

Requires **Android 8.0 or newer**. One universal APK (arm64-v8a, armeabi-v7a, x86, x86_64).
